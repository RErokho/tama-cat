# Approval policy

## Without a separate ask

- Read the open project; point edit at a known place for the current request.
- `git status` / `git diff` (not tests).
- Assign subagents low/medium/high.

## Needs explicit yes in the user message

- New product behavior not in the task/docs.
- Push, deploy, publish, new external service/MCP/cloud Graphify.
- Force push, hard reset, history wipe, bulk delete.
- Changing constitution / core kit files.
- Overwriting a Cursor file the user changed after install.

## Always forbidden

- Fast / Extra High / Grok 4.6 / 500k.
- Secrets in Git, chat, or reports.
- Editing another unnamed repo.
- Second orchestrator; subagents calling subagents.
- Silent production of experiments.
