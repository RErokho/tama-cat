# Team assembly

Coordinator = this chat. No second orchestrator. **Smallest roster** for the task type.

1. Point edit → yourself.
2. Else: `tasks` + `task-contract` (+ `task-decomposition` then `work-packet` if needed).
3. Roster: **minimum** from `references/roster.md` + `employees/registry.json`. Read **one** agent card only when launching that agent.
4. **Contract-first** on new API/types. Memory: topical (`project-memory`).
5. Compact handoff (`handoff-management` + `context-optimization`).
6. Dispatch/worktree only when multi-writer needs it.
7. Gates: `quality-gates` → `regression-awareness` → `run-gates` (use check `summary` in context).
8. `docs-lookup` / `graphify` / `noise-isolate` only on signal (`when.md`).

## Failure

Format bloat → one short retry. Same gate symptom → max 2 then escalate. Outside `allowed_files` → stop (hook + repair packet).
